# Cthangover: Story — 메인 게임

Cthangover는 형편없던 하룻밤을 보낸 마라오가 골목에서 깨어나는 이야기를 그린 블랙 코미디 비주얼 노벨입니다. 기억은 없고, 몸에는 붉은 넝마, 손에는 산 기억도 없는 낡은 책 한 권. 이 모드는 게임 자체의 콘텐츠로, 장면, 시나리오, 캐릭터, 아이템, 퀘스트, 월드 맵, 음악 선택, 그리고 이야기 텍스트를 담당합니다. 대화, 인벤토리, 전투, 맵 화면 같은 나머지 모든 것은 게임이 조합하는 엔진 모드와 메커니즘 모드가 맡습니다.

**플레이 → Cthangover → 새 게임**에서 시작합니다.

![새 게임의 첫 장면: 붉은 넝마를 두른 마라오가 어두운 골목에 서 있고, 나레이션이 그의 숙취를 묘사합니다. 프롤로그 텍스트는 현재 러시아어로만 제공됩니다.](assets/opening.jpg)

## 게임 플레이

- **프롤로그.** 이야기는 골목에서 시작해 묘지를 지나 강가를 따라 낡은 저택까지 이어집니다. 프롤로그는 소설처럼 진행됩니다: 텍스트 줄, 마라오의 초상화, 선택지.
- **저택과 마을.** 프롤로그가 끝나면 선택지로 장소를 이동합니다. 저택 바깥, 저택의 방들(현관, 거실, 부엌, 침실, 작업실, 지하), 마을 입구, 외곽.
- **생존 요소.** 새 게임은 가방에 늑대고기와 장작을 넣은 채 시작합니다. 부엌에서는 식량과 하루 소비량을 관리하고 요리도 할 수 있습니다.
- **퀘스트.** 저널이 이야기의 과제를 추적합니다. 첫 과제는 ‘각성’과 ‘낡은 집’입니다.
- **월드 맵.** 맵 패널에는 이동할 수 있는 장소와 함께 지역이 표시됩니다.
- **전투.** 전투는 기본적으로 카드 배틀을 사용하며, 게임 설정에서 커맨드식 전투로 바꿀 수 있습니다.

## 언어

프롤로그 시나리오는 러시아어로 작성되어 아직 번역이 없기 때문에, 인터페이스 언어와 관계없이 러시아어로 표시됩니다. 저택과 마을 장면, 퀘스트 저널, 아이템, 메뉴는 번역되어 있습니다.

## 게임의 구성

게임의 정체는 컬렉션 **Cthangover**입니다. 각 블록이 어떤 모드의 역할인지 보여 줍니다:

```text
이야기        cthangover_game, cthangover_murakami, cthangover_party, town_pack
2D 엔진       셸, 대화, 인터랙티브, 시간과 조명, 이펙트, 월드 맵
캐릭터        캐릭터와 스킬
퀘스트        저널
아이템        인벤토리, 요리
전투          턴제 플랫폼 + 카드 배틀(기본 코어)
전투 (FF)     커맨드식 전투 코어(선택)
영입          쓰러뜨린 캐릭터 영입(선택)
Live2D        애니메이션 아바타(선택)
인터페이스    UI 툴킷, 메뉴, 오디오
개발 도구 (선택)  에디터, 검증기, 아틀라스, 모드 관리자
```

- **Cthangover: Murakami**는 별도의 스토리 라인을 추가하고, **Cthangover: Starter Party**는 시작부터 마라오를 파티에 넣습니다. 둘 다 같은 게임의 일부지만 별개의 모드입니다.
- **Town Pack**은 마을 입구와 현관 그림을, **Music Pack**은 사운드트랙을 제공합니다. 이 모드는 마을 입구 장면 전용 재생 목록을 추가합니다.
- 컬렉션은 `battle.core`를 `card_battle`로 설정합니다. **Mods & Collections → 컬렉션 → Cthangover → 구성 편집**에서 이 값을 바꾸거나 블록의 모드를 조정할 수 있으며, 저장 파일은 그대로 유지됩니다.

## 모드 작성자를 위해

콘텐츠는 평범한 폴더에 들어 있습니다:

```filestree
cthangover_game/
├── scenes/          장소마다 JSON 하나: 이름, 배경, 환경음, 기본 시나리오
├── scenarios/       prolog/, home/, town/ 및 start.scenario
├── characters/      플레이어, 적, 스킬
├── items/           음식, 레시피, 자원
├── quests/          quests.json
├── interactives/    프롤로그 장면의 클릭 가능 오브젝트
├── map/map.json     월드 맵 구역과 마커
├── backgrounds/, avatars/, sounds/, effects/, shaders/
└── locale/          7개 언어의 이름·퀘스트·시나리오 번역
```

새 게임은 `start_scene`에서 시작하며, 이 시나리오가 초기 아이템을 지급하고 골목으로 전환합니다:

```scenario
scene: start_scene
priority: 0
is_one_run: true
---
action item.add id=food/wolf_meat count=10
action item.add id=resource/branches count=10
switch_scene prolog_alley
end
```

이 모드를 수정하지 않고 장면 텍스트를 바꾸려면 자신의 모드에 같은 장면용 시나리오를 추가하거나, `cthangover_game`에 의존성을 선언하고 같은 이름의 파일로 대체하세요.

## 문제가 생겼을 때

1. **게임 카드에 준비되지 않았다고 표시됩니다.** **플레이**에서 **빠진 것 설치**를 사용하거나 구성을 확인하세요.
2. **전투가 시작되지 않습니다.** 선택한 전투 코어가 게임에 포함되어 있어야 합니다.
3. **이야기 텍스트가 러시아어입니다.** 프롤로그이기 때문입니다(‘언어’ 참조).
