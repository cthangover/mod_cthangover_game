# Cthangover: Story — メインゲーム

Cthangover は、ひどい一夜を過ごしたマラオが路地で目を覚ますところから始まるブラックユーモアのビジュアルノベルです。記憶はなく、身には赤いぼろ布、手元には買った覚えのない古い本。この MOD はゲーム本体のコンテンツで、シーン、シナリオ、キャラクター、アイテム、クエスト、ワールドマップ、音楽の選択、そして物語のテキストを担います。それ以外の会話、インベントリ、戦闘、マップ画面は、ゲームが組み合わせるエンジン系・システム系 MOD の仕事です。

**プレイ → Cthangover → ニューゲーム** から始めます。

![ニューゲームの最初のシーン:赤いぼろ布のマラオが暗い路地に立ち、ナレーションが二日酔いを語ります。プロローグのテキストは現在ロシア語のみです。](assets/opening.jpg)

## ゲームの内容

- **プロローグ。** 物語は路地から始まり、墓地を経て川沿いを古い屋敷まで進みます。プロローグはノベル形式で、テキストの行、マラオのポートレート、選択肢で進みます。
- **屋敷と街。** プロローグの後は選択肢で場所を移動します。屋敷の外観、屋敷の部屋(玄関、居間、台所、寝室、作業部屋、地下室)、街の入り口、外れ。
- **サバイバルの要素。** ニューゲームは狼の肉と薪を背負った状態で始まります。台所では食料の在庫と一日の消費が管理され、料理もできます。
- **クエスト。** ジャーナルが物語のタスクを追跡します。最初は「目覚め」と「古い家」です。
- **ワールドマップ。** マップパネルには、移動先の場所とともに地区が表示されます。
- **戦闘。** 戦闘は既定でカードバトルを使います。ゲームの設定でコマンド式バトルへ切り替えられます。

## 言語

プロローグのシナリオはロシア語で書かれており、まだ翻訳がないため、インターフェースの言語が何であってもロシア語で表示されます。屋敷と街のシーン、クエストのジャーナル、アイテム、メニューは翻訳済みです。

## ゲームの構成

ゲームの正体はコレクション **Cthangover** です。各ブロックがどの MOD の担当かを示します:

```text
物語          cthangover_game, cthangover_murakami, cthangover_party, town_pack
2D エンジン   シェル、会話、インタラクティブ、時間と光、エフェクト、ワールドマップ
キャラクター  キャラクターとスキル
クエスト      ジャーナル
アイテム      インベントリ、料理
戦闘          ターン制プラットフォーム + カードバトル(既定のコア)
戦闘 (FF)     コマンド式バトルコア(任意)
仲間にする    倒したキャラクターを仲間にする(任意)
Live2D        アニメーションするアバター(任意)
インターフェース  UI ツールキット、メニュー、オーディオ
開発ツール (任意)  エディター、バリデーター、アトラス、MOD マネージャー
```

- **Cthangover: Murakami** は独立したストーリーラインを追加し、**Cthangover: Starter Party** は最初からマラオをパーティに入れます。どちらも同じゲームの一部ですが、別々の MOD です。
- **Town Pack** が街の入り口と玄関の画像を、**Music Pack** がサウンドトラックを提供します。この MOD は街の入り口シーン専用のプレイリストを追加しています。
- コレクションは `battle.core` を `card_battle` に設定します。**Mods & Collections → コレクション → Cthangover → 構成を編集** から、この設定も各ブロックの MOD も変更できます。セーブはそのまま残ります。

## 作者向け

コンテンツは普通のフォルダーに入っています:

```filestree
cthangover_game/
├── scenes/          場所ごとに 1 つの JSON:名前、背景、環境音、既定のシナリオ
├── scenarios/       prolog/、home/、town/、start.scenario
├── characters/      プレイヤー、敵、スキル
├── items/           食料、レシピ、素材
├── quests/          quests.json
├── interactives/    プロローグのシーンのクリック可能オブジェクト
├── map/map.json     ワールドマップのゾーンとマーカー
├── backgrounds/, avatars/, sounds/, effects/, shaders/
└── locale/          7 言語分の名前・クエスト・シナリオ翻訳
```

ニューゲームは `start_scene` から始まり、そのシナリオが初期アイテムを与えて路地へ切り替えます:

```scenario
scene: start_scene
priority: 0
is_one_run: true
---
action item.add id=food/wolf_meat count=10
action item.add id=resource/branches count=10
switch_scene prolog_alley
end
```

この MOD を編集せずにシーンのテキストを変えるには、自分の MOD に同じシーン向けのシナリオを追加するか、`cthangover_game` への依存を宣言した上で同じファイル名のファイルを上書きします。

## うまくいかないとき

1. **ゲームカードに準備未完了と表示される。** **プレイ** の **足りないものをインストール** を使うか、構成を確認してください。
2. **戦闘が始まらない。** 選択したバトルコアがゲームに含まれている必要があります。
3. **物語のテキストがロシア語。** それはプロローグです(「言語」を参照)。
