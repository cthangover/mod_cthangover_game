# Пробы реакций Марао

Тестовый набор включается флагом `--itest=marao_avatars`. Ресурс аватара:
`cthangover/marao_test`, группа пресетов: `reaction`.

| Пресет | Реакция |
| --- | --- |
| neutral | Спокойный, собранный Марао |
| hangover | «Кузнец в голове»: похмельная гримаса |
| pants_panic | «Где мои штаны?!»: возмущённое недоумение |
| rag_emperor | Самодовольный император красной тряпки |
| deadpan_azif | «Ты бумажка»: равнодушие перед Аль-Азифом |
| poetry_reader | Уверенный чтец «казахских стихов» |
| police_panic | «Я же одет… почти»: комическая паника |
| suspicious | Подозрение у виллы «Забвение» |
| bad_smell | «Ну хоть не падалью»: отвращение к запаху |
| protective | Серьёзная решимость защитить другого |

Первые четыре варианта полноростовые, остальные шесть — поясные. Каждый пресет
выбирает целую позу с выражением лица: это подборка для выбора образов, а не
раздельные детали глаз и рта. PNG прозрачные, исходные диалоговые аватарки не заменены.

[Формат и запуск проверки](en.md). Галерея с сюжетными цитатами находится вне
репозитория: `art_sources/cthangover/marao_avatar_test_20261030/index.html`.

## Обновление: общий набор с Аль-Азифом

Добавлен аватар `cthangover/al_azif_test`. Оба аватара поддерживают группу `emotion`:
`auto`, `neutral`, `open_mouth`, `eye_roll`, `confused`, `angry_scream`, `fear`, `embarrassed`,
`gloating`, `squeamish`, `disgust`, `talking_a`, `talking_b`.

По умолчанию emotion=auto сохраняет сюжетную реакцию Марао или спокойную книгу.
Явная эмоция выбирает готовое изображение целиком и перекрывает сюжетную реакцию;
для возврата нужно снова выбрать auto. Два кадра речи не образуют готовый lip sync.

У Аль-Азифа есть группа `view`: auto/front оставляют управление эмоции, angled/back/open
показывают другой ракурс и перекрывают эмоциональную картинку. Для возврата — view=auto.

Четыре полноростовые позы Марао обновлены: ноги мягче, одежда — свободные белые шорты.
В двух портретах исправлена книга. Обновлённая галерея:
`art_sources/cthangover/marao_azif_avatar_update_20261030/index.html`.
Три кадра попытки вырвать страницу находятся там же как отдельные иллюстрации.
